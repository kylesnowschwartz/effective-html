Color

Every colour is reached through a role token that names the job it does, never through a pigment name. The hex under each swatch is that role's light-mode step, and most roles select a different step in dark mode — so the swatch moves and the number does not. --panel is the exception: an inset or a code listing stays one dark surface in both modes, which is why the text on it has its own tokens.
